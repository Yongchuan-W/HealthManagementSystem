## 三、提交前必做

1. **填写团队信息**：`README.md` 与 `01-技术文档.md` 第 12 节的姓名、学号、分工，改完重新导出 docx/pdf。
2. **填写评审账号**：`02-在线演示与测试账号.md` 中的 `reviewer` 密码。
3. **确认演示地址可访问**：

   ```bash
   curl -s https://health.mymyhealth.xyz/api/health
   ```

   返回 `{"ok": true, ...}` 即可。
4. **确认公开仓库无密钥**：搜索 `HM_AI_API_KEY=`、`password`、`ai_local.env`，确认没有真实值。
5. **重命名演示视频**并检查时长、体积。
6. **重新导出 PDF**：Word 打开 docx → 另存为 PDF，检查页码与目录。
